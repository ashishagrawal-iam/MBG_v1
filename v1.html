MBG v1 — what we can ship now

The v1 build uses only two surfaces: CleverTap full-page in-app notifications for the big moments, and a single home banner with a drilldown screen for ongoing status. No changes to the assurance strip, chips, or home cards. This page recreates the full MBG journey within those limits — and the drilldown carries one steady message throughout: your bonus arrives on 16 July, you don't need to worry about it, just keep working with quality.

🔔 CleverTap full-page notification

Full-screen takeover on Home (Home-allowlisted, as today). Hero + title + body + up to 2 CTAs. Used for: announcement, opt-in, mid-cycle reassurance, and payout day. Routes via the existing PendingRouteBus on CTA tap.

📢 Home banner → drilldown

One WiomBanner in the existing purple info style, placed just below the assurance strip on Home (server-driven BannerData). Tapping opens a dedicated Bonus drilldown screen — the only place state, numbers, and the 16-July reassurance live. Persistent, always available.

Out of scope for v1 (unchanged): the assurance strip & chips, the home task feed, the wallet screens, and any new home card. All states below are expressed purely through the two surfaces above.
Reassure, don't alarm: v1 is trust-first — no "at-risk" fear messaging; the cliff nudge is deferred to a later version One steady promise: every drilldown repeats "बोनस 16 जुलाई को · चिंता न करें · क्वालिटी बनाए रखें" Quality is the only ask: the CSP's job is good work; Wiom handles the bonus math Hindi-first, warm register Reuses existing components — no new UI primitives

Stage 2 · Opt-in

Trigger: taps "और जानें" / launch follow-upCleverTap full-page (accept CTA)

Stage 3 · Bonus active (daily)

The banner + drilldown become the home of the bonus

From here on, the everyday story lives in one banner and one screen. This is the workhorse of v1 — and the drilldown's reassurance block is identical in every state.

Trigger: opt-in recorded · dailyHome banner → Bonus drilldown
  • Banner (purple info, just below the assurance strip): the existing home banner — calm and always-on — "काम करें, बिना बोनस की चिंता किए." Tapping opens the drilldown.
  • Drilldown — the reassurance block is the hero: big, brand-tinted, repeating the date, the "don't worry", and the "keep quality" message. This block is constant across every state.
  • Below it, a low-key "this month so far" row (leads, installs) — informational only, no scary gauge or red.
  • A green quality reminder and a support link round it out.
The whole v1 thesis: the CSP should never have to do bonus math or fear a cliff. One date, one promise, one instruction (quality). Everything else Wiom computes server-side.

  • CleverTap in-app pipeline — 4 full-page campaigns; CTAs route via existing PendingRouteBus + CtPageName.
  • WiomBanner — one new server-driven BannerData, tone + text vary by state. No code change.

New to build (small)

  • Bonus drilldown screen — one screen in the home nav graph: constant reassurance block + "this month so far" + quality line + support. Reads state from the home/banner payload.
  • Label file mbg_v1_labels_hi_en.json — all copy keys above.

  • Backend: banner state + leads/installs counts + bonus date (16 जुलाई, server-driven, not hardcoded) on the home payload.
